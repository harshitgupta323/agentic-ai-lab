# Agentic AI Lab

A progressive hands-on lab for building production-ready agentic AI
systems across text, documents, vision, voice, video, coding, web,
and multi-agent workflows.

## Goals

This repository explores:

- Tool calling
- ReAct agents
- Planning and execution
- Reflection
- Memory
- RAG agents
- Multimodal agents
- Voice agents
- Coding agents
- Browser agents
- Multi-agent systems
- Human-in-the-loop workflows
- MCP
- Agent evaluation
- Guardrails
- Security
- Observability
- Reliability
- Cost optimization
- Production deployment

Each project is progressively more complex.

Small projects focus on understanding a single agent
concept.

Intermediate projects combine multiple capabilities.

Flagship projects demonstrate production-oriented architecture,
evaluation, security, observability, reliability, and deployment.
